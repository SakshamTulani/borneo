# Frontend architecture (apps/web)

TanStack Start, SSR (ADR-0008). Layered feature slices (ADR-0007). Enforced by `pnpm depcruise` and `pnpm check:rules`.

## Layout

```
src/routes/             file-based routes: params, loader (prefetch), head(), compose UI. No logic.
src/routeTree.gen.ts    generated by Start; never edit
src/router.tsx          getRouter(): QueryClient + SSR query integration
src/features/<f>/
  model.ts              feature types
  api/                  raw HTTP via shared/lib/http.ts + Zod parse of DTOs
  mappers/              DTO -> model
  repository/           api + mappers; exports fetchers and queryOptions
  hooks/                one hook per file
  ui/                   components
  index.ts              public exports only
src/shared/ui, shared/lib   cross-feature UI and helpers (below features)
```

Reference slice: `src/features/health`.

## Rules (enforced)

- Imports go down only: `ui → hooks → repository → mappers → api → model`. A layer never imports its own `index.ts`.
- Other features: only via `features/<x>/index.ts`. Routes and shared code: same.
- Features never import `routes/` or `router.tsx`. `shared/` never imports features or routes.
- Only `features/*/api/` imports `shared/lib/http.ts`.
- Feature folders contain only the layers above (plus `*.test.ts(x)`).
- Hooks: only in `hooks/`, one per file, file name = hook name, named `use<Name>Query`, `use<Feature>Result` or `use<Feature>Form`.

## Rules (review)

- Business rules (price, offers, hold, serviceability, COD, returns, upgrade badge, compatibility) come from `@borneo/shared`. Never re-implemented in UI.
- SSR-safe render: no `window`, `document`, `localStorage` or `Date.now()`-dependent output during render. Leaflet, countdowns, map pins mount client-only.
- Route data: loader calls `context.queryClient.prefetchQuery(<x>Query)` with `queryOptions` from the feature repository; components read via the feature hook. No fetching in `useEffect`.
- Head tags only via `shared/lib/seo.ts` `pageHead()`.
- Filters, sort, compare selections live in URL search params (validated with Zod).
- Money arrives as paise; format only at render with the shared money helper (Phase C).
- Price block order is fixed by D-30–D-33: selling price headline, never effective price.
- Styling: Tailwind tokens from `index.css` `@theme` (DESIGN.md). No raw hex in components.
